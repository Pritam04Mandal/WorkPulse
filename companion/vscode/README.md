# WorkPulse for VS Code

Sends your coding time to the WorkPulse app on your phone over your local
network. There is no server.

It sends when you were active, the project folder name and the git repository
name. It never sends file contents, file names, full paths or anything you
type.

If this computer is already paired for Claude Code, the extension uses that
pairing. Otherwise run **WorkPulse: Pair with phone** from the Command Palette
and enter the address and code shown in the app.

Sessions arrive while the app is open on your phone. Until then they wait on
your computer.
